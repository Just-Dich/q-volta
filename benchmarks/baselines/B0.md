# B0 — NInfer vs Q-Volta on this V100 (2026-11-20), greedy, 128 new tokens, thinking off, 3 repeats each (deterministic)
Hardware: Tesla V100-SXM2-16GB, SM clock 1447-1530 MHz, 50-75 W, 47-66 C (logs/b0-*.clocks.txt). CUDA 12.9, driver 580.178.04.
Prompts: two chat prompts (code: 37 tok, prose: 47 tok). The B0 numbers below were measured with the RUSSIAN originals (binary_search in Python; why seasons change); benchmarks/bench_chat.py now holds English translations, so re-measure before comparing token-for-token. Model outputs are omitted from the JSON (they were in Russian).
NInfer: /workspace/ninfer-all build, model Qwen3.8-27B-GSQ-RCO-IQ3_S-ninfer-v3.ninfer (13.99 GiB file), flags in scripts/b0_ninfer.sh (rk4v4 KV, gdn-state-fp16, prefill-chunk 512).
Q-Volta: E0 model (RTN g64, 12.63 GiB), qv_run --bench --graph, scripts/b0_ours.sh.

Prefill (37/47-token prompts only; NOT a prefill benchmark). NInfer 289/351 tok/s. Q-Volta (token-by-token step path): the 25.6 tok/s printed by qv_run --graph was a TIMER ARTIFACT (graph mode re-recorded the end event after re-running the prompt, so it counted the prompt twice); the real step-path rate is ~51 tok/s (matches the non-graph run). Timer fixed in commit after B0.
Quality at these bytes: NOT equal. Q-Volta ppl +12% over BF16 (wikitext 4088 tok); NInfer README: +0.3% (2048-tok windows, different protocol, ratio only).
Bytes-normalized plain decode: Q-Volta 52.2 x 12.63 = 659 GiB/s eff.; NInfer 45.3 x 13.99 = 634 GiB/s (+4%). Caveat: NInfer artifact may include non-decoded tensors.


## B0b — cold prefill, identical wikitext prompts (2026-11-20), same V100, clocks 1530 MHz
NInfer (prefill-chunk 1024, rk4v4 KV, unique prompt prefix per request so the prefix cache cannot hit, 4 reps after a warmup): prompt_n 524/2062/4102 -> 837 / 1010 / 1013 tok/s (reps within 0.5%).
Q-Volta (batched prefill: dequant slab -> cuBLAS HGEMM, gdn_seq, attn_seq; chunk 512; 3 reps): 1013 / 971 / 917 tok/s for 512 / 2048 / 4088 tokens.
=> +21% at 512, -4% at 2048, -9.5% at 4088. Our loss grows with prompt length: fp32 CUDA-core attention (8.4 TFLOP/s) is quadratic; NInfer is flat.
Golden on the prefill path passes (layer rel err 6.3e-4 vs 2.0e-2 for the int8 step path; KL(qsim||engine) 7.3e-5).
Script: scripts/b0b_prefill_ninfer.sh.
